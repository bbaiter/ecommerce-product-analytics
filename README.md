# Анализ логов e-commerce

Проект посвящен полному циклу обработки и анализа сырых логов e-commerce. Включает в себя проектирование схемы базы данных, написание ETL-скриптов на Python, разведочный анализ данных (EDA) в Jupyter Notebook и расчет ключевых продуктовых метрик с помощью SQL.

## Структура проекта

```text
.
├── bd_structure/       # Схемы устройства базы данных
├── data/               # Исходные данные и файл базы данных
├── notebooks/          # Jupyter Notebook с EDA
├── scripts/            # Python-скрипты для работы с БД
├── sql/                # SQL-скрипты для расчета метрик
├── requirements.txt    # Зависимости проекта
└── README.md           # Описание проекта
```

### Описание директорий

*   **`bd_structure/`** — содержит визуализации структуры базы данных: концептуальную (`concept_map.png`), логическую (`logical_map.png`) и физическую (`physical_sceme.png`) схемы.
*   **`data/`** — директория для хранения исходных данных (`.csv`) и файла базы данных SQLite (`ecommerce.db`). 
    *   *Данные взяты c Kaggle. Датасет расположен по ссылке  https://www.kaggle.com/datasets/mkechinov/ecommerce-events-history-in-cosmetics-shop  * 
    *   Перед запуском скриптов скачайте данные и поместите их в эту папку.
*   **`notebooks/`** — содержит `Product_analytics.ipynb` с разведочным анализом данных (EDA). Анализ выполнен на примере одного месяца для выявления паттернов поведения пользователей.
*   **`scripts/`** — Python-скрипты для автоматизации работы с базой данных:
    *   `init_db.py` — инициализация базы данных и создание таблиц.
    *   `insert.py` — загрузка данных из CSV-файлов в базу данных.
    *   `select.py` — выполнение SQL-запросов к базе данных и вывод результатов.
*   **`sql/`** — SQL-скрипты для расчета основных метрик (выручка, AOV, DAU, конверсия, брошенные корзины и др.).

## Установка и запуск

1.  **Клонируйте репозиторий и перейдите в папку проекта:**
    ```bash
    git clone <url_репозитория>
    cd Eda_analysis_proj
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Подготовьте базу данных:**
    Убедитесь, что CSV-файлы лежат в папке `data/`. Затем выполните скрипты инициализации и загрузки данных:
    ```bash
    cd scripts
    python3 init_db.py
    python3 insert.py
    ```

## Использование

### Запуск SQL-запросов
Скрипт `select.py` принимает в качестве аргумента имя SQL-файла, который нужно выполнить. Скрипт автоматически находит файл в папке `sql/`, выполняет его и возвращает результат в виде таблицы (DataFrame).

Находясь в папке `scripts`, выполните:
```bash
python3 select.py average_DAU.sql
```

**Пример вывода:**
```text
     month   avg_dau  days_in_month
0  2019-10  17952.90             31
1  2019-11  18310.93             30
2  2019-12  17065.32             31
3  2020-01  19348.32             31
4  2020-02  19662.52             29
```

### Доступные SQL-метрики
В папке `sql/` находятся скрипты для расчета следующих показателей:
*   `revenue_aov_total.sql` — общая выручка, количество заказов и средний чек (AOV).
*   `revenue_aov_months.sql` — выручка и AOV в разрезе по месяцам.
*   `average_DAU.sql` — среднее количество уникальных активных пользователей в день (DAU) по месяцам.
*   `stickness.sql` — расчет метрики вовлеченности (Stickiness = DAU / MAU).
*   `conversion_rate.sql` — конверсия из просмотра в покупку и доля покупателей среди всех пользователей.
*   `abandonned_carts.sql` — доля брошенных корзин.
*   `average_buytime.sql` — среднее время от первого взаимодействия с товаром до его покупки.
*   `brannds_revenue.sql` — топ-10 брендов по выручке и количеству уникальных покупателей.
